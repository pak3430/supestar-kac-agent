지식이 어떻게 행동이 되고,
검증된 답변으로 바뀌는가

이 구조는 질문과 답을 미리 저장해 두는 시스템이 아닙니다. 미리 구조화한 것은 AI가 관찰할 수 있는 지식·관계·실행 규칙이고, 매 질문에서 Local LLM이 현재 Observation을 보고 다음 행동을 선택합니다. 선택의 연속은 관계사슬과 SkillRun이 되고, 그 실행 증거에 닫힌 claim만 답변으로 공개됩니다.

⑤ KAC SkillRun

모델이 고른 원자 Skill을 실제 코드로 실행합니다. 입력·판정·규칙 trace·출처·관계경로 hash가 실행 증거가 됩니다.

↺ Observation → LLM 판단 → Action → 새 Observation

⑦ Fail-closed Verifier

Anchor·활성 edge 전체·SkillRun·출처·개념 근거가 닫혔을 때만 PASS합니다. 미통과 문장은 공개하지 않습니다.

verify_candidate() · PASS / REVIEW

“행동”은 관계 자체가 아닙니다. AI가 Observation을 보고 다음 지식을 관찰하거나 edge를 선택하고 Skill을 실행하는 상태 변화가 행동입니다.

2. 단일 질문과 관계 질문은 어디서 갈라지는가

Anchor 개수는 실행 범위를 정하지만 답변을 정하지 않습니다. 두 경우 모두 Skill 실행과 검증은 필수입니다.

SINGLE ANCHOR

“ESG가 무엇입니까?”

Anchor: ESG 1개

관계가 둘 이상인 질문이 아니므로 Agentic 1-hop 관계 탐색을 생략합니다. 그렇다고 고정 정의를 바로 반환하지는 않습니다.

1ESG Anchor 관찰

2LLM이 Skill 선택

현재 허용 catalog 안에서 선택

3SkillRun 실행

ESG 행동 경로 계약 실제 실행

4Claim 1개 생성

관찰 근거로 질문에 직접 답함

“지식 하나만 읽는다”가 아니라 “관계 탐색이 불필요한 단일 중심 개념 질문”으로 실행 범위를 좁힙니다.

4. JSON은 세 종류이며 서로 대체되지 않습니다

“JSON을 사용한다”는 사실만으로 RAG나 고정 답변이 되는 것은 아닙니다. 생성 시점과 책임이 핵심입니다.

TYPE A · PREBUILT
