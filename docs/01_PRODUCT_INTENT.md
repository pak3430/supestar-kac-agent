# 제품 의도

## 만드는 것

수페스타 v3는 Local Qwen이 CCS 지식 환경과 KAC Skill 도구 안에서 스스로 다음 행동을 선택하는 챗봇입니다.

사용자가 질문에 포함하지 않은 연결 개념도 Qwen이 필요성을 판단해 관찰할 수 있어야 합니다. 개발자가 질문별 정답 경로를 코드로 지정하지 않습니다.

## 행동의 정의

이 프로젝트에서 AI의 행동은 문장을 생성하는 것만을 뜻하지 않습니다.

1. 질문에서 의미적 anchor를 인식한다.
2. 시작 anchor의 1-hop 관계만 관찰한다.
3. 현재 Observation에 실제 존재하는 edge 하나를 선택한다.
4. 새 node의 1-hop 관계를 보고 선택·backtrack·종료를 결정한다.
5. 완성한 관계사슬을 근거로 KAC Skill을 선택한다.
6. Skill Observation을 읽고 답변 제출 또는 추가 행동을 결정한다.

## 보여주어야 하는 장면

사용자 질문과 최종 답변 사이에서 다음 항목이 시간순으로 보여야 합니다.

- Qwen이 선택한 다음 행동
- 관찰한 Identity·Knowledge·관계
- 매 단계에 제시된 1-hop 후보와 실제로 선택한 edge
- 잘못된 분기에서의 backtrack 또는 근거 부족 STOP
- 호출한 원자 Skill과 입력
- SkillRun에 결합된 AI 관계사슬 hash
- Skill이 반환한 판정·근거·가드레일
- 다음 행동을 선택한 이유의 짧은 공개용 요약
- 검증기의 승인·보완·중단 판정

비공개 내부 추론 전체를 노출하지 않고, 감사 가능한 행동과 근거만 표시합니다.

전체 최단경로를 먼저 계산해 모델에게 주지 않습니다. 결정론적 경로 알고리즘은 AI의 탐색이 끝난 뒤 경로 단절과 우회를 비교하는 사후 검증기로만 사용합니다.
